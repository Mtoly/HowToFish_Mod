STATIC_FINDINGS
1. TacticalSlideMod.SlideController is a DontDestroyOnLoad MonoBehaviour singleton.
2. IsSliding, SlideProgress, and CurrentSlideDir are static process-wide state.
3. SlideController.Update reads input and calls UpdateVisualInterpolation.
4. StartSlide sets IsSliding, local timer, direction, audio and particle effects.
5. ApplySlidePhysics subtracts Time.fixedDeltaTime, computes boost/slope boost, and writes Rigidbody.linearVelocity every movement pass.
6. OnSlideHop writes Rigidbody.linearVelocity and ends sliding locally.
7. EndSlide and CancelSlide only clear local state; no explicit network state event is present.
8. PlayerMovementPatch gates input/physics on Owner.IsLocalClient for FixedUpdate, Move, and Jump.
9. Crouch visual/collider handling checks sliding state without an explicit owner gate.
10. The plugin references FishNet.Runtime, but the decompiled TacticalSlide code has no visible ServerRpc, ObserversRpc, Broadcast, SyncVar, or NetworkBehaviour state component for sliding.
11. Game PlayerMovement derives from FishNet.NetworkBehaviour and writes _rig.linearVelocity in its own FixedUpdate/Move path.
12. Game PlayerMovement has a TargetRpc for knockback only; no slide state field or slide RPC was found in the exported PlayerMovement source.
