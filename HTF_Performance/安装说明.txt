渔力全开锁帧优化mod v1.0.0
作者：镜桦izumik

支持范围
========
Windows 10/11 x64、Steam 正版《How to Fish》、Unity Mono、BepInEx 5.4.x。
不支持 BepInEx 6、IL2CPP、Proton、Steam Deck 或非 Steam 版本。

先找到正确的游戏内层目录
========================
正确目录必须同时包含：
1. How to Fish.exe
2. How to Fish_Data 文件夹

纯净游戏手动安装
================
1. 完全退出游戏。
2. 打开本 ZIP 的“载荷\纯净游戏”。
3. 把其中全部内容复制到上述游戏内层目录。
4. 同意合并目录；若出现与现有加载器相关的覆盖提示，请取消并改用自动安装器检查环境。

已有 BepInEx 5.4.x 手动安装
============================
1. 完全退出游戏。
2. 确认现有版本确实是 BepInEx 5.4.x，而不是 6.x 或 IL2CPP 版。
3. 打开本 ZIP 的“载荷\已有BepInEx”。
4. 把其中全部内容复制到游戏内层目录。

自动安装
========
把本 ZIP 与“渔力全开锁帧优化mod-v1.0.0-自动安装.exe”放在同一目录，运行 EXE，先核对目标路径和逐项文件清单，再确认执行。
EXE 不内嵌载荷、不联网、不调用脚本，且默认不请求管理员权限。

卸载
====
优先使用同一 EXE 的“检查卸载”和“执行卸载”。卸载只删除本 Mod 安装清单中的文件，不删除 BepInEx、其他插件或游戏文件。
手动卸载时只删除：
BepInEx\plugins\渔力全开锁帧优化mod

校验
====
发布目录的 SHA256SUMS.txt 记录完整 ZIP 与 EXE 的 SHA-256。
ZIP 内 payload-manifest.tsv 记录安装载荷逐文件 SHA-256；BepInEx-官方文件-SHA256.txt 单独记录官方加载器文件。

提示
====
本安装器没有 Authenticode 证书，Windows 可能显示“未知发布者”或 SmartScreen 提示。这与安全软件明确检出恶意代码不是同一件事。若校验值不一致，请勿运行。
